# 🇬🇧 English

## 📌 About

**UnicodeForge** is a professional CLI tool for generating, inspecting, and analyzing Unicode text.

It supports random Unicode string generation, repeating patterns, randomized pattern variations, Unicode character-set libraries, character analysis, normalization, statistics, and exporting generated data to TXT and JSON.

The project is designed for **Unicode experimentation, decorative text generation, character analysis, and testing Unicode string behavior**.

## ✨ Features

* 🔤 Generate random Unicode strings
* 🔁 Create and automatically repeat patterns
* 🎲 Generate random variations of patterns
* 📚 Built-in Unicode Character Set library
* 🧩 Create custom Character Sets
* 🔍 Inspect and analyze Unicode characters
* 🔢 Display Unicode Code Points
* 🏷️ Display Unicode character names
* 🧹 Unicode text normalization
* 📐 Detect and inspect text normalization forms
* 📊 Display generated-string statistics
* 🔢 Count unique characters
* 🔁 Count character repetitions
* 📄 Export results to TXT
* 🗂️ Export results to JSON
* 🖥️ Clean and professional CLI interface
* 📴 Works completely offline
* 🌐 No external API required

## ⚙️ How It Works

UnicodeForge provides a command-line environment where users can generate or analyze Unicode text.

The general workflow is:

1. Select a Unicode operation.
2. Configure the required parameters.
3. Generate or provide the target text.
4. Analyze Unicode characters and properties.
5. Display statistics and normalization information.
6. Export the result when needed.

## 🔤 Unicode Analysis

UnicodeForge can inspect individual characters and provide information such as:

* Unicode Code Point
* Character name
* Character frequency
* Unique character count
* Repetition statistics
* Normalization information

## 🎲 Pattern Generator

The pattern system allows users to create repeating Unicode structures and introduce randomized variations.

This makes the tool useful for experimenting with:

* Repeating Unicode patterns
* Decorative text
* Randomized strings
* Character-set combinations
* Unicode behavior testing

## 📚 Character Sets

UnicodeForge includes a collection of Unicode Character Sets and also allows users to create their own custom sets.

Custom sets can be used as the source for random string and pattern generation.

## 📊 Statistics

Generated strings can be analyzed to provide information such as:

* 📏 String length
* 🔢 Number of unique characters
* 🔁 Character frequencies
* 🧩 Character distribution
* 🔤 Unicode information
* 🧹 Normalization status

## 📦 Export

Generated and analyzed results can be exported in:

* `.txt`
* `.json`

This makes it easier to use the generated data in other tools or projects.

## 🖥️ CLI

UnicodeForge uses a clean command-line interface designed to keep Unicode generation and analysis organized and easy to use.

## 📴 Offline

UnicodeForge does not require:

* 🌐 Internet access
* 🔑 API keys
* ☁️ External services

All supported generation and analysis operations can be performed locally.

## 🎯 Use Cases

UnicodeForge can be useful for:

* Unicode experimentation
* Character analysis
* Text-generation experiments
* Decorative text generation
* Pattern testing
* Unicode normalization testing
* Software development and debugging
* Learning Unicode internals
